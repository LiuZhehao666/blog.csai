# 前言
>LangChain是连接AI模型与实际AI应用的桥梁。

过去一年，大模型像一阵“龙卷风”席卷各行各业：它能写代码、写方案、写文案。很多人是：把 API 接上就完事了。可一上真实业务，你很快会发现大模型确实聪明，但它更像一位“只负责动脑的军师”：会分析、会推理、会表达，却看不见实时数据、摸不着业务系统、记不住长期上下文，不会自己把任务拆开推进。

这就带来一个关键问题：我们真正想要的，不是一个会背诵互联网海量数据的“百科全书”，而是一个能理解目标、制定计划、调用工具、与业务流程协作的智能伙伴（Agent）。也就是说，大模型不仅只需要脑子，还得有“眼睛”（检索数据）、“手脚”（工具调用与执行）、“记忆”（对话与状态）、以及一套能把思考串成行动的“神经系统”（流程编排）。

如果把场景画成一条小溪：一岸是大模型，另一岸是实际应用的世界。过去我们怎么过河？最直接的办法当然是“趟过去”（也就是直接调用 API）。能到达，但鞋子一定会湿，天天跑就容易滑倒。

而 LangChain 更像是在小溪上架起一座桥：它不替你变出更大的“脑子”，而是把过河这件事工程化——把提示词、记忆、检索、工具调用、链式流程与代理决策这些“桥面和护栏”搭好，让大模型从“能说”升级为“会做”，从“单次回答”变成能融入业务流程的智能伙伴（Agent）。

这正是 LangChain 这类框架存在的意义：它不制造更聪明的脑子，而是提供一整套把脑子接入现实世界的工程化方法——从提示词组织、链式推理，到检索增强、记忆管理，再到工具调用与代理决策，让大模型从“能说”走向“会做”，从“单次回答”升级为“持续协作”。

简单说：大模型负责聪明，LangChain负责让聪明真正落地。
