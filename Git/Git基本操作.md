# 认识Git
> 工作或者学习的过程中写文档，不符合预期，第一次修改，还是不符合预期，第二次修改，反复多次，改了很多次，比如五次，结果发现第一版最好，这个时候你只有第五次的版本，拿不到第一版，怎么解决？每次的版本去创建副本，比如文档V1，文档V2......文档V5，这个时候你每一版本都在电脑中，需要任意一版都可以。但是有一个问题，这是我们只有五个版本，如果有五十个版本，甚至上百个版本，并且需要找到具体添加某个功能的版本，有没有办法找到？那是不是需要一个一个看，所以维护版本非常困难，各自版本修改的内容还是什么我们记不住。所以版本控制器就诞生了

版本控制器是可以记录每次的修改以及版本迭代的管理系统

Git是目前最主流的版本控制器，可以控制电脑上所有格式的文件/文档

对于开发人员来说，使用Git最主要的用途是管理项目中的源代码文件。

对于文本文件是可以记录下每次修改的内容是什么，但是我们还会有二进制文件，比如图片，视频，没有办法跟踪文件具体的变化，可以知道图片从100kb-200kb，不知道具体的改变内容。
