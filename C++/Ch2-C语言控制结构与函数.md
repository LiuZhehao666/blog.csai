# C语言控制结构与函数

## 1. 运算符

### 1.1 算术运算符

C语言提供基本的算术运算：

```c
#include <stdio.h>

int main() {
    int a = 10, b = 3;
    
    printf("a + b = %d\n", a + b);  // 加法：13
    printf("a - b = %d\n", a - b);  // 减法：7
    printf("a * b = %d\n", a * b);  // 乘法：30
    printf("a / b = %d\n", a / b);  // 除法：3（整数除法）
    printf("a %% b = %d\n", a % b); // 取余：1
    
    return 0;
}
```

**专业解释**：整数除法会截断小数部分，只保留整数部分。取余运算符`%`返回两个数相除的余数。

**通俗解释**：
- 整数除法就像"分苹果"：10个苹果分给3个人，每人3个，剩下1个。所以`10 / 3 = 3`（不是3.33）。
- 取余`%`就是"剩下的"：10除以3，商是3，余数是1，所以`10 % 3 = 1`。
- 注意：`printf`中打印`%`需要用`%%`，因为`%`是格式符的标记。

### 1.2 关系运算符

用于比较两个值的大小关系：

```c
#include <stdio.h>

int main() {
    int a = 10, b = 20;
    
    printf("a == b: %d\n", a == b);  // 等于：0（假）
    printf("a != b: %d\n", a != b);  // 不等于：1（真）
    printf("a < b: %d\n", a < b);    // 小于：1（真）
    printf("a > b: %d\n", a > b);    // 大于：0（假）
    printf("a <= b: %d\n", a <= b);  // 小于等于：1（真）
    printf("a >= b: %d\n", a >= b);  // 大于等于：0（假）
    
    return 0;
}
```

**专业解释**：关系运算符返回整数值：0表示假（false），非0（通常是1）表示真（true）。在C语言中，没有专门的布尔类型，用整数表示真假。

**通俗解释**：关系运算符就像"判断题"，结果是"对"（1）或"错"（0）。比如`10 < 20`是对的，所以结果是1；`10 == 20`是错的，所以结果是0。

### 1.3 逻辑运算符

用于组合多个条件：

```c
#include <stdio.h>

int main() {
    int a = 10, b = 20, c = 30;
    
    // && 逻辑与：两个条件都为真，结果才为真
    printf("a < b && b < c: %d\n", a < b && b < c);  // 1
    
    // || 逻辑或：至少一个条件为真，结果就为真
    printf("a > b || b < c: %d\n", a > b || b < c);  // 1
    
    // ! 逻辑非：取反
    printf("!(a < b): %d\n", !(a < b));  // 0
    
    return 0;
}
```

**专业解释**：
- `&&`（逻辑与）：短路求值，如果左边为假，右边不再计算
- `||`（逻辑或）：短路求值，如果左边为真，右边不再计算
- `!`（逻辑非）：一元运算符，将真变假，假变真

**通俗解释**：
- `&&`就像"而且"：两个条件都要满足。比如"今天下雨而且有伞"，两个都满足才能出门。
- `||`就像"或者"：满足一个就行。比如"今天下雨或者有伞"，满足一个就可以出门。
- `!`就像"不是"：把对的说成错的，错的说成对的。

**短路求值示例**：
```c
int x = 0;
if (x != 0 && 10 / x > 5) {  // 安全：因为x==0，左边为假，右边不会计算
    printf("安全\n");
}
```

### 1.4 赋值运算符

```c
int a = 10;
a += 5;   // 等价于 a = a + 5，结果a=15
a -= 3;   // 等价于 a = a - 3，结果a=12
a *= 2;   // 等价于 a = a * 2，结果a=24
a /= 4;   // 等价于 a = a / 4，结果a=6
a %= 5;   // 等价于 a = a % 5，结果a=1
```

**通俗解释**：这些是"简化写法"。`a += 5`就是"把a加上5，结果存回a"，比写`a = a + 5`更简洁。

### 1.5 自增自减运算符

```c
int a = 10;
a++;      // 后置自增：先使用a的值，然后a加1
++a;      // 前置自增：先a加1，然后使用a的值
a--;      // 后置自减：先使用a的值，然后a减1
--a;      // 前置自减：先a减1，然后使用a的值
```

**专业解释**：前置运算符先改变值再使用，后置运算符先使用再改变值。

**通俗解释**：
```c
int a = 10;
int b = a++;  // 后置：先把a的值(10)给b，然后a变成11
// 结果：a=11, b=10

int c = 10;
int d = ++c;  // 前置：先把c加1变成11，然后把11给d
// 结果：c=11, d=11
```

### 1.6 运算符优先级

运算符有优先级，就像数学中的"先乘除后加减"：

```c
int result = 2 + 3 * 4;  // 结果是14，不是20
// 因为*优先级高于+，先算3*4=12，再算2+12=14
```

**建议**：不确定优先级时，使用括号明确运算顺序：
```c
int result = (2 + 3) * 4;  // 结果是20
```

## 2. 条件语句

### 2.1 if语句

**基本语法**：
```c
if (条件) {
    // 条件为真时执行的代码
}
```

**示例**：
```c
#include <stdio.h>

int main() {
    int score = 85;
    
    if (score >= 60) {
        printf("及格了！\n");
    }
    
    return 0;
}
```

**专业解释**：`if`语句根据条件表达式的真假决定是否执行代码块。条件为真（非0）时执行，为假（0）时不执行。

**通俗解释**：`if`就像"如果...就..."。如果条件满足（比如分数>=60），就执行大括号里的代码（打印"及格了"）。

### 2.2 if-else语句

```c
if (条件) {
    // 条件为真时执行
} else {
    // 条件为假时执行
}
```

**示例**：
```c
#include <stdio.h>

int main() {
    int score = 85;
    
    if (score >= 60) {
        printf("及格了！\n");
    } else {
        printf("不及格！\n");
    }
    
    return 0;
}
```

**通俗解释**：`if-else`就像"如果...就...否则就..."。如果分数>=60，打印"及格了"；否则（分数<60），打印"不及格"。

### 2.3 if-else if-else语句

用于多个条件判断：

```c
#include <stdio.h>

int main() {
    int score = 85;
    
    if (score >= 90) {
        printf("优秀\n");
    } else if (score >= 80) {
        printf("良好\n");
    } else if (score >= 60) {
        printf("及格\n");
    } else {
        printf("不及格\n");
    }
    
    return 0;
}
```

**专业解释**：`else if`可以链式使用，按顺序检查条件，执行第一个为真的分支，然后跳过后续所有分支。

**通俗解释**：就像"如果...就...，否则如果...就...，否则如果...就...，否则就..."。程序从上到下检查，找到第一个满足的条件就执行，然后结束。

### 2.4 嵌套if语句

```c
#include <stdio.h>

int main() {
    int age = 20;
    int hasLicense = 1;  // 1表示有，0表示没有
    
    if (age >= 18) {
        if (hasLicense) {
            printf("可以开车\n");
        } else {
            printf("年龄够了，但没有驾照\n");
        }
    } else {
        printf("年龄不够，不能开车\n");
    }
    
    return 0;
}
```

**通俗解释**：嵌套if就像"大判断里套小判断"。先判断年龄是否>=18，如果满足，再判断是否有驾照。

### 2.5 三元运算符（条件运算符）

```c
条件 ? 值1 : 值2
```

如果条件为真，返回值1；否则返回值2。

**示例**：
```c
#include <stdio.h>

int main() {
    int a = 10, b = 20;
    int max = (a > b) ? a : b;  // 如果a>b，max=a，否则max=b
    printf("最大值: %d\n", max);
    
    return 0;
}
```

**通俗解释**：三元运算符就像"一句话的if-else"。`(a > b) ? a : b`意思是"如果a>b就选a，否则选b"。

## 3. switch语句

用于多分支选择：

```c
switch (表达式) {
    case 常量1:
        // 代码
        break;
    case 常量2:
        // 代码
        break;
    default:
        // 代码
}
```

**示例**：
```c
#include <stdio.h>

int main() {
    int day = 3;
    
    switch (day) {
        case 1:
            printf("星期一\n");
            break;
        case 2:
            printf("星期二\n");
            break;
        case 3:
            printf("星期三\n");
            break;
        case 4:
            printf("星期四\n");
            break;
        case 5:
            printf("星期五\n");
            break;
        default:
            printf("周末\n");
    }
    
    return 0;
}
```

**专业解释**：
- `switch`根据表达式的值跳转到匹配的`case`标签
- `break`用于跳出`switch`，防止"穿透"到下一个`case`
- `default`是可选的，处理所有不匹配的情况

**通俗解释**：
- `switch`就像"多路开关"：根据表达式的值，选择对应的"开关"（case）执行。
- `break`就像"停止按钮"：执行完当前case后，遇到`break`就停止，不再继续执行后面的case。如果没有`break`，会"穿透"执行后面的所有case（这通常不是我们想要的）。
- `default`就像"其他情况"：如果所有case都不匹配，就执行default。

**注意**：`switch`只能用于整型、字符型或枚举类型，不能用于浮点型或字符串。

## 4. 循环语句

### 4.1 while循环

**语法**：
```c
while (条件) {
    // 循环体
}
```

只要条件为真，就重复执行循环体。

**示例**：
```c
#include <stdio.h>

int main() {
    int i = 1;
    
    while (i <= 5) {
        printf("%d ", i);
        i++;  // 重要：改变循环变量，否则会无限循环
    }
    printf("\n");
    
    return 0;
}
// 输出：1 2 3 4 5
```

**专业解释**：`while`循环先检查条件，条件为真时执行循环体，然后再次检查条件，如此反复，直到条件为假。

**通俗解释**：`while`就像"只要...就一直..."。只要条件满足（比如i<=5），就一直执行大括号里的代码。注意要在循环体内改变条件相关的变量（如`i++`），否则会无限循环。

### 4.2 do-while循环

**语法**：
```c
do {
    // 循环体
} while (条件);
```

先执行一次循环体，然后检查条件，条件为真则继续循环。

**示例**：
```c
#include <stdio.h>

int main() {
    int i = 1;
    
    do {
        printf("%d ", i);
        i++;
    } while (i <= 5);
    
    printf("\n");
    return 0;
}
```

**专业解释**：`do-while`与`while`的区别是，`do-while`至少执行一次循环体，因为条件检查在循环体之后。

**通俗解释**：`do-while`就像"先做...然后检查..."。不管条件如何，先执行一次，然后再判断是否继续。这适用于"至少执行一次"的场景。

### 4.3 for循环

**语法**：
```c
for (初始化; 条件; 更新) {
    // 循环体
}
```

**示例**：
```c
#include <stdio.h>

int main() {
    int i;
    
    for (i = 1; i <= 5; i++) {
        printf("%d ", i);
    }
    printf("\n");
    
    return 0;
}
// 输出：1 2 3 4 5
```

**专业解释**：`for`循环的执行顺序：
1. 执行初始化（只执行一次）
2. 检查条件，如果为假则退出
3. 执行循环体
4. 执行更新
5. 回到步骤2

**通俗解释**：`for`循环把"初始化、条件、更新"都写在一行，更紧凑。`for (i = 1; i <= 5; i++)`意思是：
- 开始时：i = 1（初始化）
- 只要：i <= 5（条件）
- 每次循环后：i++（更新）

**for循环的变体**：
```c
// 可以省略初始化（如果之前已初始化）
int i = 1;
for (; i <= 5; i++) {
    printf("%d ", i);
}

// 可以省略更新（在循环体内更新）
for (int i = 1; i <= 5; ) {
    printf("%d ", i);
    i++;
}

// 可以省略所有部分（无限循环）
for (;;) {
    // 无限循环，需要用break退出
}
```

### 4.4 嵌套循环

循环内可以包含另一个循环：

```c
#include <stdio.h>

int main() {
    int i, j;
    
    // 打印九九乘法表
    for (i = 1; i <= 9; i++) {
        for (j = 1; j <= i; j++) {
            printf("%d*%d=%d\t", j, i, i * j);
        }
        printf("\n");
    }
    
    return 0;
}
```

**通俗解释**：嵌套循环就像"大循环里套小循环"。外层循环执行一次，内层循环完整执行一遍。比如打印九九乘法表：外层控制行（1到9行），内层控制每行的列数。

### 4.5 break和continue

**break**：跳出当前循环

```c
#include <stdio.h>

int main() {
    int i;
    for (i = 1; i <= 10; i++) {
        if (i == 5) {
            break;  // 当i等于5时，跳出循环
        }
        printf("%d ", i);
    }
    printf("\n循环结束\n");
    return 0;
}
// 输出：1 2 3 4
// 循环结束
```

**continue**：跳过本次循环，继续下一次

```c
#include <stdio.h>

int main() {
    int i;
    for (i = 1; i <= 10; i++) {
        if (i == 5) {
            continue;  // 跳过i=5这次循环
        }
        printf("%d ", i);
    }
    printf("\n循环结束\n");
    return 0;
}
// 输出：1 2 3 4 6 7 8 9 10
// 循环结束
```

**通俗解释**：
- `break`就像"紧急停止"：遇到它，整个循环立即结束。
- `continue`就像"跳过这一轮"：遇到它，不执行后面的代码，直接开始下一轮循环。

## 5. 函数

### 5.1 什么是函数

**专业解释**：函数是一段完成特定任务的代码块，可以被多次调用。函数提高了代码的复用性和可维护性。

**通俗解释**：函数就像"工具"或"机器"：你给它输入（参数），它按照设计好的步骤工作，然后给你输出（返回值）。比如"计算器"就是一个函数：输入两个数字，输出它们的和。

### 5.2 函数的定义和调用

**函数定义语法**：
```c
返回类型 函数名(参数列表) {
    // 函数体
    return 返回值;  // 如果返回类型不是void
}
```

**示例**：
```c
#include <stdio.h>

// 函数定义：计算两个数的和
int add(int a, int b) {
    int sum = a + b;
    return sum;
}

int main() {
    int result = add(3, 5);  // 函数调用
    printf("3 + 5 = %d\n", result);
    return 0;
}
```

**专业解释**：
- 函数定义包括：返回类型、函数名、参数列表、函数体
- 函数调用时，实参的值会传递给形参
- `return`语句结束函数执行并返回一个值

**通俗解释**：
- `int add(int a, int b)`：定义一个函数，名字叫`add`，接收两个整数参数`a`和`b`，返回一个整数。
- `add(3, 5)`：调用这个函数，把3传给a，5传给b，函数计算后返回8。
- `return sum;`：把计算结果返回给调用者。

### 5.3 无参数无返回值函数

```c
#include <stdio.h>

void printHello() {
    printf("Hello, World!\n");
}

int main() {
    printHello();  // 调用函数
    return 0;
}
```

**通俗解释**：`void`表示"没有"。`void printHello()`表示这个函数不接收参数，也不返回值，只是执行一些操作（打印Hello）。

### 5.4 有参数无返回值函数

```c
#include <stdio.h>

void printNumber(int num) {
    printf("数字是: %d\n", num);
}

int main() {
    printNumber(42);
    return 0;
}
```

### 5.5 有参数有返回值函数

```c
#include <stdio.h>

int max(int a, int b) {
    if (a > b) {
        return a;
    } else {
        return b;
    }
}

int main() {
    int result = max(10, 20);
    printf("最大值: %d\n", result);
    return 0;
}
```

### 5.6 函数声明

如果函数定义在调用之后，需要先声明：

```c
#include <stdio.h>

// 函数声明（告诉编译器函数的存在）
int add(int a, int b);

int main() {
    int result = add(3, 5);  // 调用
    printf("结果: %d\n", result);
    return 0;
}

// 函数定义（实际实现）
int add(int a, int b) {
    return a + b;
}
```

**专业解释**：函数声明告诉编译器函数的签名（返回类型、函数名、参数类型），让编译器知道如何检查函数调用是否正确。函数定义提供函数的实际实现。

**通俗解释**：函数声明就像"预告"：告诉编译器"有个函数叫add，接收两个int，返回int"。这样编译器在遇到`add(3, 5)`时就知道这是合法的。函数定义在后面，提供具体实现。

### 5.7 参数传递：值传递

**重要概念**：C语言中，函数参数是"值传递"（传值）。

```c
#include <stdio.h>

void swap(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
    printf("函数内: a=%d, b=%d\n", a, b);
}

int main() {
    int x = 10, y = 20;
    printf("调用前: x=%d, y=%d\n", x, y);
    swap(x, y);
    printf("调用后: x=%d, y=%d\n", x, y);
    return 0;
}
```

**输出**：
```
调用前: x=10, y=20
函数内: a=20, b=10
调用后: x=10, y=20
```

**专业解释**：值传递意味着函数接收的是实参的副本，函数内对参数的修改不会影响原始变量。

**通俗解释**：值传递就像"复印"：你把原件（x, y）复印一份，把复印件（a, b）给函数。函数在复印件上修改，原件不变。所以`swap`函数无法交换`main`函数中的`x`和`y`。要实现真正的交换，需要使用指针（后面会学到）。

### 5.8 递归函数

函数可以调用自己，这叫做递归：

```c
#include <stdio.h>

// 计算阶乘：n! = n * (n-1)!
int factorial(int n) {
    if (n <= 1) {
        return 1;  // 递归终止条件
    }
    return n * factorial(n - 1);  // 递归调用
}

int main() {
    int result = factorial(5);
    printf("5! = %d\n", result);  // 输出：120
    return 0;
}
```

**专业解释**：递归函数必须有两个要素：
1. 递归终止条件（基础情况）
2. 递归关系（如何从大问题分解为小问题）

**通俗解释**：递归就像"套娃"或"镜子里的镜子"：
- 计算5!时，需要先计算4!
- 计算4!时，需要先计算3!
- ...
- 计算1!时，直接返回1（终止条件）
- 然后一层层返回，最终得到5!

**递归执行过程**（以factorial(3)为例）：
```
factorial(3)
  → 3 * factorial(2)
      → 2 * factorial(1)
          → 1  (返回1)
      → 2 * 1 = 2  (返回2)
  → 3 * 2 = 6  (返回6)
```

**注意**：递归要小心，必须有终止条件，否则会无限递归导致栈溢出。

## 6. 作用域和存储类别

### 6.1 局部变量和全局变量

```c
#include <stdio.h>

int global = 100;  // 全局变量

void func() {
    int local = 50;  // 局部变量
    printf("全局变量: %d\n", global);
    printf("局部变量: %d\n", local);
}

int main() {
    func();
    printf("全局变量: %d\n", global);
    // printf("局部变量: %d\n", local);  // 错误！local在func内，main访问不到
    return 0;
}
```

**通俗解释**：
- 全局变量：在函数外面定义，整个程序都能用，就像"公共财产"。
- 局部变量：在函数里面定义，只能在这个函数里用，就像"私人财产"。

### 6.2 static关键字

`static`修饰的局部变量在函数调用之间保持值：

```c
#include <stdio.h>

void counter() {
    static int count = 0;  // static局部变量
    count++;
    printf("调用次数: %d\n", count);
}

int main() {
    counter();  // 输出：调用次数: 1
    counter();  // 输出：调用次数: 2
    counter();  // 输出：调用次数: 3
    return 0;
}
```

**专业解释**：`static`局部变量只初始化一次，在程序运行期间一直存在，但作用域仍然是局部的。

**通俗解释**：普通局部变量就像"临时便签"，函数结束就销毁。`static`局部变量就像"带锁的盒子"，函数结束后值还在，下次调用时继续使用。
