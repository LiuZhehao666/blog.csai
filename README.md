## 图片添加方法

每个分类目录下都有自己的 `images/` 目录。把图片文件放进去，然后在对应的 Markdown 文档里用相对路径引用：

```markdown
![说明](./images/xxx.png)
```

例如把图片放到 `Vue/images/demo.png`，就在 `Vue` 相关文档里写：

```markdown
![Vue示例](./images/demo.png)
```
